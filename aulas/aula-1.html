Prepare a bancada de edição

Você consegue abrir um projeto e importar quatro clipes organizados.

Um projeto perdido ou uma fonte movida pode interromper a edição. Comece pequeno e preserve os arquivos.

Em 1 minuto

  1. Fontes: quatro clipes do kit
  2. Projeto: Verde Perto
  3. Teste: fechar a tela do projeto e reabrir

1Projeto é a montagem, fonte é o material

Projeto guarda escolhas de edição; os clipes são arquivos de origem.

Crie a pasta Verde Perto com fontes, voz e entregas.

Nanda, editora de 28 anos, ajuda Jorge, professor de 60 anos.

Eles preparam um convite para uma oficina de jardinagem.

Baixe e extraia o kit desta aula pelo aplicativo de arquivos.

Há quatro clipes verticais silenciosos de cinco segundos.

Foram feitos com imagens do Codex e movimento de aproximação.

Não mostram ações filmadas nem crescimento real de plantas.

Nanda mantém o kit original separado das versões exportadas.

Baixar kit de quatro clipes e imagens · Origem do material

Quatro imagens do Codex animadas com aproximação. Cada clipe tem cinco segundos, sem áudio; não são ações filmadas nem crescimento real de plantas.

2Abra o editor com um teste curto

No CapCut para computador, escolha Novo projeto ou Create project.

Em Mídia, use Importar e selecione os quatro clipes.

Nomeie o projeto Verde Perto.

Procure o nome na tela inicial depois de voltar; abra novamente para confirmar que foi guardado.

O curso usa o aplicativo de computador como referência.

Celular e navegador podem oferecer controles diferentes.

Se aparecer cobrança, identifique o recurso antes de continuar.

Na aula 3, faremos uma exportação curta para conhecer a condição da sua conta.

Jorge anota a pasta para encontrá-la sem depender da memória.

3Confira a decisão pelo uso

Guardar fontes numa pasta estável e confirmar que o projeto reabre.

Jorge usa a ficha para conferir: teste: fechar a tela do projeto e reabrir.

Teste-se

O editor informa que uma fonte está ausente. Qual é o primeiro passo?

Se travou aqui, é normalSe não conseguir abrir o editor, mantenha esta prática pendente. Ler o caminho não substitui reabrir o projeto.

Prepare a bancada de edição

Reserve cerca de 10 minutos de trabalho ativo para este recorte. Processamento fica fora desse tempo. Pronto quando o projeto reabre e mostra os quatro arquivos importados.

Use arquivos próprios ou autorizados. Recursos do editor podem depender de conta e plano. Mantenha atividades não executadas como pendentes e preserve os originais.
