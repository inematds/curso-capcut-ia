Use máscara para revelar uma parte

Você consegue montar uma janela visual com borda controlada.

Máscara e remoção de fundo resolvem problemas diferentes. Uma forma geométrica pode bastar para a comparação.

Em 1 minuto

  1. Camada superior: região revelada
  2. Forma: posição e tamanho
  3. Borda: contraste e suavidade

1Máscara limita a área visível

Coloque uma cópia do clipe numa faixa superior.

Selecione essa cópia e procure Máscara no painel de vídeo.

Escolha uma forma simples, como retângulo ou círculo.

Ajuste tamanho e posição para mostrar só a região desejada.

A máscara não reconhece necessariamente o contorno da planta.

Ela revela uma área definida pela forma.

Para comparar detalhe e conjunto, mostre uma janela do detalhe sobre uma imagem mais aberta.

Preserve espaço entre a janela e o assunto principal.

Nanda usa uma janela para comparar escalas de observação.

2Suavidade é uma escolha de borda

O controle de suavização da borda, chamado feather em algumas versões, torna a transição menos marcada.

Use pouco para um recorte legível.

Suavizar demais pode apagar o limite e criar uma mancha.

Observe a janela no tamanho de um celular.

Se animar, confira o que está selecionado: a máscara ou a transformação do vídeo.

Mover uma não é sempre mover o outro.

Faça primeiro uma janela estática.

Movimento adicional só entra quando ajuda a comparação.

Jorge mantém a janela afastada do convite escrito.

3Confira a decisão pelo uso

Posicionar uma janela simples e ajustar a borda pela leitura no quadro final.

Jorge usa a ficha para conferir: borda: contraste e suavidade.

Teste-se

O que uma máscara circular faz neste exercício?

Se travou aqui, é normalSe a borda parecer confusa, retire a suavização e volte a uma forma simples. Mais efeitos não resolvem falta de espaço.
